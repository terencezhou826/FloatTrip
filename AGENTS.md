# FloatTrip Project Working Agreements

1. Architecture is provincial; current content scope is Changzhi only.
2. Changzhi is content and configuration, not program logic.
3. Core architecture must not be bound to mythology.
4. Prefer configuration and repository lookup over regional conditional branches.
5. Reuse FloatTrip before rewriting it.
6. Real-world POIs must eventually come from verified providers.
7. Cultural claims must eventually have traceable evidence.
8. Historical fact, mythology, local legend, academic interpretation, and promotional wording must remain distinguishable.
9. AI video is optional and disabled by default.
10. Video generation must eventually go through `VideoProvider`.
11. Avoid premature infrastructure.
12. Every milestone requires automated tests.
13. Runtime and SSE semantics must not be changed without explicit architectural approval.
